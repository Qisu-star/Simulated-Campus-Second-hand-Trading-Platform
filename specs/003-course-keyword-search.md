# 003：课程关键词搜索

> 状态：提议中，未实施  
> 关联事项：[ADR-002：课程搜索的职责与数据访问边界](../docs/adr/002-course-search-responsibility-boundary.md)

本 Spec 描述计划中的课程关键词搜索行为。正式实现前须先同步 `contracts/openapi.yaml`；当前 Contract 与后端尚未提供该能力。

## 目标

学习者可以用一个简短关键词缩小课程目录范围，并能稳定区分匹配、无匹配和非法输入。

## 用户故事

作为一名学习者，我希望按课程标题或简介搜索课程，以便在课程数量增多时快速找到感兴趣的内容。

## 范围

- 在现有课程集合查询中接受一个可选关键词。
- 定义关键词缺失、空白、正常、特殊字符和超长时的稳定语义。
- 定义匹配字段、大小写、空结果、排序、错误和字段结构。
- 为每条验收标准规划可重复的 Service、API 或 Contract 验证。

## 非目标

- 不实现前端搜索框、输入联想、搜索历史或关键词高亮。
- 不引入分页、相关度排序、拼写纠正、分词或全文搜索引擎。
- 不改变课程字段、默认 `id` 升序或现有无关键词调用方的结果语义。
- 在本 Spec 被采纳并进入实现前，不修改 Contract、后端代码或数据库结构。

## 业务规则

- **BR-01**：`keyword` 是可选的单值 Query 参数；同一请求出现多个 `keyword` 值时视为非法输入。
- **BR-02**：服务端先去除 `keyword` 首尾空白。参数缺失或归一化后为空时，行为与现有课程列表一致。
- **BR-03**：非空关键词在课程 `title` 与 `description` 中做包含匹配；ASCII 字母 `A-Z` 不区分大小写，任一字段命中即返回该课程。
- **BR-04**：归一化后的关键词最多包含 80 个 Unicode 字符；`%`、`_` 和 `\` 按普通字符匹配，不具有 SQL 通配符语义。
- **BR-05**：成功结果始终返回 `{ "data": Course[] }` 并按 `id` 升序；无匹配项返回 `200` 和 `{ "data": [] }`。
- **BR-06**：重复或超过长度上限的 `keyword` 返回 `400` 和 `VALIDATION_FAILED`；客户端能通过稳定错误结构识别失败。
- **BR-07**：未预期的数据库失败返回 `500` 和 `INTERNAL_ERROR`；响应不得包含 SQL、堆栈、数据库路径或密钥，错误体、`X-Request-Id` 响应头与日志使用同一个 `requestId`。
- **BR-08**：所有成功与失败响应都包含非空 `X-Request-Id`；成功响应不需要在 JSON 中重复该值。

## Contract 影响

- 结论：变更（计划中；当前 Contract 未修改）。
- 理由或影响摘要：为现有课程集合增加可选 `keyword` Query；不携带参数的旧调用保持原语义，因此计划为向后兼容变更。需要补充 `400`、`500`、统一错误 Schema 与 `X-Request-Id`。
- OpenAPI operation：计划变更 `GET /api/courses`（`listCourses`）。
- 迁移 / 废弃安排：无废弃；正式实现前先更新 `contracts/openapi.yaml` 并通过评审。

## 验收标准

- **AC-01**：给定课程表包含多条记录，当请求 `GET /api/courses`、省略 `keyword` 或传入仅含空白的 `keyword` 时，响应为 `200`，`data` 包含全部课程并按 `id` 升序。
- **AC-02**：给定标题或简介包含 `web` 的课程，当请求 `GET /api/courses?keyword=%20web%20` 时，服务端去除首尾空白，响应为 `200`，且只返回标题或简介包含 `web` 的课程。
- **AC-03**：给定课程标题包含 `Web`，当分别使用 `keyword=web` 与 `keyword=WEB` 请求时，两次响应包含相同的课程集合和顺序。
- **AC-04**：给定没有课程匹配归一化后的关键词，当请求课程列表时，响应为 `200` 和 `{ "data": [] }`，不返回 `404` 或 `500`。
- **AC-05**：给定课程数据不包含 `%`、`_` 或 `\`，当分别以这三个字符作为关键词请求课程列表时，每次响应均为 `200` 和 `{ "data": [] }`，不会把字符解释为 SQL 通配或转义语法。
- **AC-06**：给定归一化后的 `keyword` 超过 80 个 Unicode 字符或同一请求包含多个 `keyword`，当请求课程列表时，响应为 `400`，错误代码为 `VALIDATION_FAILED`，错误体中的 `requestId` 与 `X-Request-Id` 响应头一致。
- **AC-07**：给定课程查询发生数据库异常，当请求课程列表时，响应为 `500` 和 `INTERNAL_ERROR`，错误体不包含 SQL、堆栈或数据库路径，且错误体、`X-Request-Id` 响应头与对应错误日志中的 `requestId` 一致。
- **AC-08**：给定任一成功的课程列表查询，当服务端返回 `200` 时，响应包含非空 `X-Request-Id` 头，课程 JSON Schema 不因该头而改变。
