# 009：页面布局与导航

> 状态：草案  
> 关联事项：影响所有已有 Spec 和后续 Spec 的页面入口与跳转关系

## 目标

统一网站全局导航结构，明确各页面之间的跳转关系，为后续功能开发提供布局框架。

## 全局导航栏

固定在页面顶部，在所有页面均可见。

| 导航项 | 链接目标 | 说明 |
|--------|----------|------|
| 主界面入口 | 浏览页 | 如"网站名称"或"首页"文字/图标链接 |
| 搜索框 | 搜索结果页 | 输入关键词回车后跳转 |
| 个人界面入口 | 下拉菜单（详见 010） | 未登录 → 跳转登录页；已登录 → 展开下拉菜单含个人中心、我的商品、我的订单、账户 |

| 购物车入口 | 购物车页 | 详见 012-交易系统，未登录时引导登录 |

## 页面跳转关系

```text
浏览页 ──点击商品卡片──→ 商品详情页
浏览页 ──搜索────────→ 搜索结果页
搜索结果页 ──点击商品卡片──→ 商品详情页

商品详情页 ──点击商家名称──→ 商家主页
商品详情页 ──收藏──→ 收藏页

收藏页 ──商品标签──点击商品──→ 商品详情页
收藏页 ──商家标签──点击商家──→ 商家主页

商家主页 ──点击商品卡片──→ 商品详情页

导航栏 ──个人入口（未登录）──→ 登录/注册页
导航栏 ──个人入口（已登录）──→ 展开下拉菜单
导航栏 ──收藏入口──→ 收藏页
导航栏 ──购物车入口──→ 购物车页（详见 012-交易系统）

个人界面（下拉菜单）──个人中心──→ 个人中心页
个人界面（下拉菜单）──我的商品──→ 商家商品管理页
个人界面（下拉菜单）──我的订单──→ 订单页（详见 012-交易系统）
个人界面（下拉菜单）──账户──→ 账户页（详见 012-交易系统）
个人界面（下拉菜单）──审核管理──→ 审核页（管理员专属，详见 013-后台审核）
```

## 业务规则

- **BR-01**：全局导航栏在所有页面固定显示，不因页面滚动而隐藏。
- **BR-02**：导航栏中"个人界面入口"根据登录状态切换：未登录显示"登录/注册"链接或按钮，点击跳转登录页；已登录显示用户名或图标，点击展开下拉菜单（含个人中心、我的商品、我的订单、账户）。
- **BR-03**：需要登录才能访问的页面（收藏页、购物车页、个人中心、商家商品管理页、订单页、账户页），未登录用户访问时跳转至登录页，登录后回跳至目标页。
- **BR-04**：分类筛选栏仅在浏览页、搜索结果页和商家主页显示，其他页面不显示。
- **BR-05**：每个页面有独立的 URL 路径，支持浏览器前进/后退导航。

## 验收标准

- **AC-01**：访问任意页面，导航栏均显示在顶部。
- **AC-02**：未登录时点击导航栏"个人界面入口"，跳转至登录页；登录后自动回跳。
- **AC-03**：已登录时点击导航栏"个人界面入口"，跳转至个人界面。
- **AC-04**：点击导航栏主界面入口，跳转至浏览页。
- **AC-05**：在导航栏搜索框输入关键词并回车，跳转至搜索结果页。
- **AC-06**：分类筛选栏在浏览页、搜索结果页和商家主页显示，在商品详情页和收藏页不显示。
